# Этап 2 — конфигурация

__Сборка:__
make

### !ВНИМАНИЕ! 
По заданию нужен MakeFile. Данный MakeFile использует g++, а поэтому:

Для "чистой" Windows:
1. Установите MinGW (или MSYS2)
2. Запустите: mingw32-make

__Параметры запуска:__
./emulator --vfs PATH --prompt TEXT --script PATH
// через терминал

! Все параметры необязательны; если не указаны, используются значения по умолчанию.

--> vfs путь к будущему источнику VFS (на этом этапе только сохраняется в конфигурации)

--> prompt строка приглашения REPL

--> script путь к файлу команд, выполняемому при старте

--> Служебная команда:
conf-dump

--> Тестирование:
sh scripts/test_all.sh
sh scripts/test_parameter_combinations.sh

Стартовый скрипт scripts/start.txt намеренно содержит неизвестную команду:
эмулятор должен вывести ошибку и продолжить выполнять следующие строки.
