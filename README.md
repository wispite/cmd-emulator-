# CMD Emulator

## Описание проекта

CMD Emulator — программа, имитирующая работу командной строки с использованием виртуальной файловой системы (VFS).

Виртуальная файловая система загружается из указанной директории на диске в оперативную память. Все дальнейшие операции выполняются с её внутренним представлением, без изменения исходных файлов на диске.

## Основные возможности

- Загрузка виртуальной файловой системы из директории пользователя.
- Отображение структуры файлов и папок.
- Перемещение между директориями.
- Отображение текущего пути.
- Настройка приглашения командной строки.
- Выполнение команд из текстового скрипта.
- Обработка некорректных команд и аргументов.

## Сборка и запуск

Для сборки проекта используется Makefile:

```bash
make
```

Запуск эмулятора с основной виртуальной файловой системой:

```bash
./vfs-emulator --vfs myVFS
```

Запуск с тестовой файловой системой:

```bash
./vfs-emulator --vfs tests/vfs_many
```

Запуск с выполнением команд из скрипта:

```bash
./vfs-emulator --vfs tests/vfs_many --script tests/startup.txt
```

## Основные команды

| Команда | Назначение |
|---|---|
| `ls` | Отображение содержимого текущей директории |
| `cd <путь>` | Переход в указанную директорию |
| `pwd` | Отображение текущего пути |
| `exit` | Завершение работы эмулятора |

## Тестирование

Для проверки работы программы предусмотрены три варианта виртуальной файловой системы:

- **vfs_empty** — пустая файловая система.
- **vfs_many** — файловая система с несколькими файлами и вложенной директорией.
- **vfs_deep** — файловая система с несколькими уровнями вложенности.

Для автоматического запуска тестов используются shell-скрипты:

```bash
./scripts/test_empty.sh
./scripts/test_many.sh
./scripts/test_deep.sh
```

Общий сценарий проверки команд находится в `tests/startup.txt`.
