# Этап 2 — конфигурация

## Описание проекта

Проект представляет собой консольный эмулятор командной оболочки операционной системы, разработанный на C++.

Второй этап работы посвящён конфигурации приложения: передаче параметров через командную строку и выполнению команд эмулятора из стартового скрипта.

### Реализованные возможности

- Интерактивный режим работы с командной оболочкой (REPL).
- Разбор введённых команд и аргументов, включая аргументы в двойных кавычках.
- Обработка команд `ls`, `cd` и `exit`.
- Передача параметров конфигурации при запуске приложения.
- Выполнение команд из стартового скрипта.
- Отображение выполняемых команд и результатов их выполнения.
- Обработка ошибок при выполнении команд и стартового скрипта.

## Требования

Для сборки проекта необходимы:

- Компилятор C++ с поддержкой C++17.
- Утилита `make`.

## Сборка проекта

Для сборки проекта выполните команду из корневой директории репозитория:

```bash
make
```

После успешной сборки исполняемый файл будет создан под именем `vfs-emulator`.

Для очистки результатов сборки используйте:

```bash
make clean
```

## Запуск приложения

Приложение поддерживает два режима работы: интерактивный режим и выполнение стартового скрипта.

### Интерактивный режим

Для запуска эмулятора используйте:

```bash
./vfs-emulator
```

После запуска пользователь может вводить команды в приглашении командной оболочки.

Пример взаимодействия:

```text
MyVFS:~$ ls -l
Command: ls
Arguments: -l

MyVFS:~$ cd "My Documents"
Command: cd
Arguments: My Documents

MyVFS:~$ exit
Bye!
```

### Запуск с параметрами конфигурации

При запуске можно указать путь к виртуальной файловой системе (VFS) и путь к стартовому скрипту.

Общий вид команды:

```bash
./vfs-emulator --vfs <путь_к_VFS> --script <путь_к_скрипту>
```

Параметры:

| Параметр | Назначение |
|---|---|
| `--vfs` | Путь к физическому расположению VFS. |
| `--script` | Путь к стартовому скрипту с командами эмулятора. |

При запуске с параметрами приложение выводит отладочную информацию о заданной конфигурации.

> Названия параметров в примере необходимо привести в соответствие с фактическими именами аргументов, используемыми в реализации.

## Стартовый скрипт

Стартовый скрипт содержит последовательность команд, которые эмулятор выполняет автоматически при запуске.

Каждая команда записывается на отдельной строке. При выполнении скрипта приложение отображает выполняемую команду и результат её обработки, имитируя диалог с пользователем.

Пример содержимого файла `scripts/startup.txt`:

```text
ls
ls -l
cd "My Documents"
unknown_command
exit
```

При выполнении скрипта команды обрабатываются последовательно. Если одна из команд завершается ошибкой, приложение сообщает об ошибке в соответствии с предусмотренным алгоритмом обработки ошибок.

## Примеры использования

### Запуск со стартовым скриптом

```bash
./vfs-emulator --vfs ./vfs --script ./scripts/startup.txt
```

### Запуск с другим стартовым скриптом

```bash
./vfs-emulator --vfs ./vfs --script ./scripts/test-errors.txt
```

### Проверка обработки аргументов в кавычках

```text
MyVFS:~$ cd "My Documents"
```

Парсер рассматривает текст в двойных кавычках как единый аргумент, даже если он содержит пробел.

### Проверка обработки ошибок

```text
MyVFS:~$ unknown_command
Error: unknown command
```

Неизвестная команда должна обрабатываться корректно, без аварийного завершения приложения.
