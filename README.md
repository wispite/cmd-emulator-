## Этап 1 — REPL
Добро пожаловать!
Это эмулятор командной оболочки для UNIX-подобной операционной системы.

Проект разрабатывается поэтапно. На первом этапе реализован минимальный
интерактивный прототип, болванка REPL (Read-Eval-Print Loop).

На данном этапе уже реализованы:

- консольный интерфейс командной строки;
- приглашение к вводу с именем VFS;
- разбор введённой команды на имя команды и аргументы;
- поддержка аргументов, заключённых в двойные кавычки;
- команда `ls` в виде заглушки;
- команда `cd` в виде заглушки;
- команда `exit` для завершения работы;
- обработка неизвестных команд;
- обработка незакрытых кавычек.
- и так далее...

Команды `ls` и `cd`  не выполняют так таковых операции с файловой
системой. Они выводят распознанное имя команды и переданные аргументы.

## Структура проекта
```text
cmd-emulator/
├── src/
│   └── main.cpp
├── tests/
├── .gitignore
├── Makefile
└── README.md
```

### `src/`
Содержит исходный код эмулятора командной оболочки.

### `tests/`
Каталог для автоматизированных тестов проекта. На этапе 1 такие тесты пока
не реализованы.

### `Makefile`
Содержит команды для сборки, запуска и очистки проекта.

## Сборка проекта
Для сборки проекта используется `make`:
```bash
make
```

ланируется реализация виртуальной файловой системы, а
поддержка дополнительных команд и операций над файлами и каталогами.
