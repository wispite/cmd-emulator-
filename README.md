# Этап 3. Виртуальная файловая система (VFS)

## Цель этапа

Реализовать подключение виртуальной файловой системы (VFS), содержимое которой загружается из директории на диске в оперативную память. Все дальнейшие операции выполняются с загруженной структурой данных без изменения исходных файлов.

## Реализованные возможности

В рамках третьего этапа реализованы:

- Загрузка файлов и директорий из указанной папки на диске в оперативную память.
- Представление файловой системы в виде дерева узлов (`Node`).
- Хранение информации об имени элемента, его типе, содержимом, родительском узле и дочерних элементах.
- Подключение VFS к эмулятору при запуске.
- Отображение дерева виртуальной файловой системы.
- Работа с несколькими вариантами структуры VFS для тестирования.

## Тестирование

Для проверки работы реализованы три тестовые файловые системы:

| Тестовая директория | Назначение |
|---|---|
| `tests/vfs_empty` | Проверка работы с пустой файловой системой |
| `tests/vfs_many` | Проверка работы с несколькими файлами и директориями |
| `tests/vfs_deep` | Проверка работы с вложенными директориями (не менее трёх уровней) |

Для автоматизации тестирования созданы shell-скрипты:

- `scripts/test_empty.sh` — запуск эмулятора с пустой VFS.
- `scripts/test_many.sh` — запуск с несколькими файлами и автоматическим выполнением тестового сценария.
- `scripts/test_deep.sh` — запуск с глубокой вложенностью директорий.

Также создан файл `tests/startup.txt`, содержащий последовательность команд для автоматической проверки работы VFS и обработки ошибок.

## Использование

Для запуска тестов необходимо находиться в корневой директории проекта.

Запуск с пустой файловой системой:

```bash
./scripts/test_empty.sh
```

Запуск с несколькими файлами:

```bash
./scripts/test_many.sh
```

Запуск с глубокой вложенностью:

```bash
./scripts/test_deep.sh
```

Для самостоятельного указания директории VFS используется параметр `--vfs`:

```bash
./vfs-emulator --vfs myVFS
```

Для запуска с автоматическим выполнением команд из файла сценария:

```bash
./vfs-emulator --vfs tests/vfs_many --script tests/startup.txt
```

## Результат

В результате третьего этапа реализована загрузка виртуальной файловой системы из директории на диске в оперативную память. Подготовлены тестовые структуры различной сложности и shell-скрипты для проверки их работы. Проверена корректность загрузки файлов и директорий, включая пустые файловые системы и структуры с несколькими уровнями вложенности.
