# CMD Emulator
Добро пожаловать!
Это эмулятор командной оболочки для UNIX-подобной операционной системы.

Проект разрабатывается поэтапно. На первом этапе реализован минимальный
интерактивный прототип, болванка REPL (Read-Eval-Print Loop).

## Этап 1 — REPL

На данном этапе уже реализованы:

- консольный интерфейс командной строки;
- приглашение к вводу с именем VFS;
- разбор введённой команды на имя команды и аргументы;
- поддержка аргументов, заключённых в двойные кавычки;
- команда `ls` в виде заглушки;
- команда `cd` в виде заглушки;
- команда `exit` для завершения работы;
- обработка неизвестных команд;
- обработка незакрытых кавычек.
- и так далее...

Команды `ls` и `cd`  не выполняют так таковых операции с файловой
системой. Они выводят распознанное имя команды и переданные аргументы.

## Структура проекта
```text
cmd-emulator/
├── src/
│   └── main.cpp
├── tests/
├── .gitignore
├── Makefile
└── README.md
```

### `src/`
Содержит исходный код эмулятора командной оболочки.

### `tests/`
Каталог для автоматизированных тестов проекта. На этапе 1 такие тесты пока
не реализованы.

### `Makefile`
Содержит команды для сборки, запуска и очистки проекта.

### `.gitignore`
Содержит список файлов и каталогов, которые не должны попадать в
репозиторий: артефакты сборки, настройки IDE и системные файлы.

## Сборка проекта
Для сборки проекта используется `make`:
```bash
make
```

После успешной сборки создаётся исполняемый файл:
```text
vfs-emulator
```

## Запуск
Для сборки и запуска программы:
```bash
make run
```

Также программу можно запустить непосредственно после сборки:
```bash
./vfs-emulator
```

## Очистка
Для удаления результата сборки:
```bash
make clean
```

## Пример использования
После запуска программа выводит приглашение:
```text
MyVFS:~$
```

### Команда `ls`
```text
MyVFS:~$ ls
command: ls
arguments: none
```

### `ls` с аргументами
```text
MyVFS:~$ ls file.txt documents
command: ls
arguments: [file.txt] [documents]
```

### Аргумент в кавычках

Аргумент, содержащий пробелы, можно заключить в двойные кавычки:
```text
MyVFS:~$ ls "my folder"
command: ls
arguments: [my folder]
```

В данном случае `my folder` воспринимается как один аргумент.

### Команда `cd`
```text
MyVFS:~$ cd "my folder"
command: cd
arguments: [my folder]
```

На этапе 1 команда является заглушкой и не изменяет текущий каталог.

### Неизвестная команда
```text
MyVFS:~$ hello
err: unknown command 'hello'
```

### Незакрытая кавычка
```text
MyVFS:~$ ls "my folder
err: Unclosed quote
```

После обработки ошибки программа продолжает работу и снова выводит
приглашение.

### Завершение работы
```text
MyVFS:~$ exit
bye bye! ;) 
```
