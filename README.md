# Этап 5. Дополнительные команды эмулятора

## 1. Общее описание

На данном этапе функциональность эмулятора командной строки расширена командой `touch`, предназначенной для создания файлов в виртуальной файловой системе.

Реализация учитывает основные требования проекта: изменения состояния VFS выполняются только в оперативной памяти и не приводят к непосредственному изменению файловой системы хостовой операционной системы.

Команда интегрирована с ранее реализованными средствами обработки команд, навигацией по виртуальным каталогам и механизмом обработки ошибок.

## 2. Функции и настройки

### 2.1. Команда `touch`

Команда `touch` предназначена для создания нового пустого файла в текущем виртуальном каталоге.

Синтаксис:

```text
touch <имя_файла>
```

Параметры:

- `имя_файла` — имя создаваемого файла в виртуальной файловой системе.

При успешном выполнении команды в текущем виртуальном каталоге появляется новый файл.

### 2.2. Работа с виртуальной файловой системой

Команда работает с текущим состоянием VFS и учитывает текущий виртуальный каталог.

Создаваемые файлы существуют в рамках виртуальной файловой системы эмулятора. Исходные файлы и каталоги хостовой операционной системы не изменяются.

### 2.3. Обработка ошибок

При выполнении команды обрабатываются следующие ситуации:

- отсутствие имени файла;
- некорректное имя файла;
- попытка создания файла в недоступном каталоге;
- конфликт имени с уже существующим объектом, если такое поведение предусмотрено реализацией.

При обнаружении ошибки эмулятор выводит соответствующее сообщение и продолжает работу.

### 2.4. Совместимость с предыдущими командами

Команда `touch` работает совместно с ранее реализованными командами:

- `ls` — для проверки появления созданного файла;
- `cd` — для перехода между виртуальными каталогами;
- `pwd` — для определения текущего виртуального пути;
- `wc` — для получения характеристик содержимого файла.

## 3. Сборка и запуск тестов

Сборка проекта:

```bash
make
```

Запуск эмулятора:

```bash
./vfs-emulator --vfs ./test-vfs
```

Запуск стартового сценария тестирования:

```bash
bash tests/startup_test.sh
```

Стартовый сценарий включает проверки команд предыдущих этапов, команды `touch`, различных режимов использования команд и обработки ошибок.

Очистка результатов сборки:

```bash
make clean
```

## 4. Примеры использования

### Пример 1. Создание файла

```text
MyVFS:~$ touch notes.txt
MyVFS:~$
```

В текущем виртуальном каталоге создаётся пустой файл `notes.txt`.

### Пример 2. Проверка созданного файла

```text
MyVFS:~$ touch notes.txt
MyVFS:~$ ls
notes.txt
```

Команда `ls` используется для проверки появления файла в содержимом текущего виртуального каталога.

### Пример 3. Создание файла во вложенном каталоге

```text
MyVFS:~$ cd documents
MyVFS:~/documents$ touch report.txt
MyVFS:~/documents$ ls
report.txt
```

Файл создаётся в текущем виртуальном каталоге `documents`.

### Пример 4. Получение информации о созданном файле

```text
MyVFS:~$ touch empty.txt
MyVFS:~$ wc empty.txt
```

Команда `wc` вызывается для проверки работы с созданным файлом. Для пустого файла ожидаются нулевые значения счётчиков, если именно такое поведение предусмотрено реализацией.

### Пример 5. Обработка ошибки

```text
MyVFS:~$ touch
Error: missing filename
```

При отсутствии обязательного аргумента выводится сообщение об ошибке.

## 5. Результат этапа

Реализована команда `touch` для создания файлов в виртуальной файловой системе. Команда интегрирована с механизмом обработки ошибок и командами, разработанными на предыдущих этапах. Подготовлен стартовый сценарий для комплексной проверки функциональности эмулятора.
