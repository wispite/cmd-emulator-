# VFS Emulator

Эмулятор командной оболочки UNIX-подобной операционной системы.

## Этап 1 — REPL

На первом этапе реализован минимальный интерактивный прототип командной оболочки.

Поддерживается:        

- `ls` — заглушка команды вывода имени и аргументов;
- `cd` — заглушка команды вывода имени и аргументов;
- `exit` — завершение работы эмулятора.

Реализован парсер с поддержкой кавычек.
