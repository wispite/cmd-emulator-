# Этап 4. Основные команды эмулятора

## 1. Общее описание

На данном этапе расширен набор команд эмулятора командной строки. Реализована логика работы с виртуальной файловой системой и добавлены команды, имитирующие поведение команд UNIX-подобных операционных систем.

Эмулятор поддерживает навигацию по виртуальным каталогам, получение информации о текущем каталоге и подсчёт строк, слов и символов в файлах.

Все операции выполняются в рамках виртуальной файловой системы. Работа с VFS не приводит к непосредственному изменению файлов и каталогов хостовой операционной системы.

## 2. Функции и настройки

### 2.1. Команда `ls`

Команда `ls` предназначена для отображения содержимого текущего виртуального каталога.

Пример:

```text
MyVFS:~$ ls
file.txt
documents
notes.txt
```

Команда позволяет просматривать доступные файлы и каталоги.

### 2.2. Команда `cd`

Команда `cd` используется для изменения текущего виртуального каталога.

Пример:

```text
MyVFS:~$ cd documents
MyVFS:~/documents$
```

Команда поддерживает переходы между каталогами в пределах VFS. При указании несуществующего каталога выводится сообщение об ошибке.

### 2.3. Команда `pwd`

Команда `pwd` выводит путь к текущему виртуальному каталогу.

Пример:

```text
MyVFS:~/documents$ pwd
/documents
```

### 2.4. Команда `wc`

Команда `wc` предназначена для подсчёта характеристик содержимого файла.

Поддерживаются следующие показатели:

- количество строк;
- количество слов;
- количество символов.

Пример:

```text
MyVFS:~$ wc notes.txt
```

Результат содержит рассчитанные значения для указанного файла.

### 2.5. Обработка ошибок

Реализована обработка ошибок, возникающих при выполнении команд, включая:

- неизвестную команду;
- отсутствие обязательного аргумента;
- указание несуществующего файла или каталога;
- попытку перехода в недоступный каталог;
- некорректные аргументы команды.

При возникновении ошибки эмулятор выводит сообщение и продолжает работу.

## 3. Сборка и запуск тестов

Сборка проекта:

```bash
make
```

Запуск эмулятора:

```bash
./vfs-emulator --vfs ./test-vfs
```

Запуск стартового сценария тестирования:

```bash
bash tests/startup_test.sh
```

Стартовый сценарий включает проверки ранее реализованных команд, команд текущего этапа, различных режимов их использования и обработки ошибок.

Очистка результатов сборки:

```bash
make clean
```

## 4. Примеры использования

### Пример 1. Просмотр содержимого каталога

```text
MyVFS:~$ ls
documents
notes.txt
```

Команда выводит список объектов текущего виртуального каталога.

### Пример 2. Переход в каталог

```text
MyVFS:~$ cd documents
MyVFS:~/documents$ 
```

После выполнения команды текущим становится виртуальный каталог `documents`.

### Пример 3. Получение текущего пути

```text
MyVFS:~/documents$ pwd
/documents
```

Команда отображает путь текущего каталога внутри VFS.

### Пример 4. Подсчёт содержимого файла

```text
MyVFS:~$ wc notes.txt
```

Эмулятор анализирует указанный виртуальный файл и выводит количество строк, слов и символов.

### Пример 5. Обработка ошибки

```text
MyVFS:~$ cd missing_directory
Error: directory not found
```

При обращении к несуществующему каталогу выводится сообщение об ошибке, после чего можно продолжить ввод команд.

## 5. Результат этапа

Реализованы команды `ls`, `cd`, `pwd` и `wc`, обеспечивающие навигацию по виртуальной файловой системе, просмотр содержимого каталогов и получение информации о файлах. Подготовлен стартовый сценарий для комплексного тестирования команд и обработки ошибок.
