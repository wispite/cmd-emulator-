# Этап 3. Виртуальная файловая система (VFS)

## 1. Общее описание

На данном этапе в эмулятор командной строки добавлена виртуальная файловая система (Virtual File System, VFS).

VFS предназначена для имитации работы с файлами и каталогами без непосредственного изменения файловой системы хостовой операционной системы. Источником виртуальной файловой системы является указанная директория на диске пользователя.

Все операции с содержимым VFS выполняются в оперативной памяти. Изменения, выполняемые командами эмулятора, не изменяют исходные файлы и каталоги на диске.

Также реализованы сценарии автоматического тестирования, позволяющие проверить работу виртуальной файловой системы с различными структурами каталогов.

## 2. Функции и настройки

### 2.1. Подключение VFS

При запуске эмулятора указывается путь к директории, используемой в качестве источника виртуальной файловой системы.

Пример:

```bash
./vfs-emulator --vfs ./test-vfs
```

В качестве источника может использоваться директория с минимальным набором файлов, несколькими файлами и каталогами либо вложенной структурой с несколькими уровнями.

### 2.2. Работа с виртуальной файловой системой

Реализованы следующие возможности:

- подключение директории хостовой системы в качестве источника VFS;
- представление файлов и каталогов в виртуальной файловой системе;
- выполнение операций над виртуальной структурой в оперативной памяти;
- сохранение исходного содержимого файловой системы хоста без изменений;
- обработка ошибок, связанных с некорректными путями и операциями.

### 2.3. Сценарии тестирования

Подготовлены скрипты реальной операционной системы для проверки работы эмулятора с различными вариантами VFS:

- минимальная структура с небольшим количеством объектов;
- структура с несколькими файлами и каталогами;
- вложенная структура с глубиной не менее трёх уровней.

Каждый сценарий запускает эмулятор с соответствующим набором тестовых данных.

## 3. Сборка и запуск тестов

Для сборки проекта используется `make`:

```bash
make
```

Запуск эмулятора с тестовой виртуальной файловой системой:

```bash
./vfs-emulator --vfs ./test-vfs
```

Запуск сценария тестирования:

```bash
bash tests/vfs_test.sh
```

Если в проекте используется другой каталог или имя тестового скрипта, необходимо указать фактический путь.

Очистка результатов сборки:

```bash
make clean
```

## 4. Примеры использования

### Пример 1. Подключение минимальной VFS

```bash
./vfs-emulator --vfs ./tests/data/minimal
```

Эмулятор подключает подготовленную директорию и использует её содержимое в качестве начальной структуры VFS.

### Пример 2. Подключение VFS с несколькими файлами

```bash
./vfs-emulator --vfs ./tests/data/multiple-files
```

Пример предназначен для проверки обработки нескольких файлов и каталогов.

### Пример 3. Подключение вложенной структуры

```bash
./vfs-emulator --vfs ./tests/data/nested
```

Данный сценарий позволяет проверить работу с каталогами, вложенными на несколько уровней.

### Пример 4. Запуск автоматического тестирования

```bash
bash tests/vfs_test.sh
```

Сценарий последовательно запускает эмулятор для проверки различных структур VFS и обработки ошибок.

## 5. Результат этапа

Реализована виртуальная файловая система, работающая в оперативной памяти и использующая директорию хостовой системы в качестве источника данных. Подготовлены сценарии тестирования для различных вариантов структуры файлов и каталогов.
